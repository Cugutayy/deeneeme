# Figma Wireframe Plan (Cinematic Scenes)

## Frame System
- Desktop: 1440 x 5200 (12-column grid, 80px margins)
- Mobile: 390 x 4600 (4-column grid, 20px margins)
- Visual rhythm: every section is a **scene** with cinematic spacing and photo-led blocks.

## Home — Scene by Scene
1. **Scene 1 / Hero Film**
   - Black pre-roll frame (0.8s), then fullscreen running video loop.
   - Kinetic title: `ALSANCAK RUNNERS` -> `RUN THE CITY`.
   - Scroll cue: `↓ SCROLL TO RUN`.
2. **Scene 2 / Community Moment**
   - Fullscreen editorial image (stairs / stretch / lace tie).
   - Slow scroll zoom + overlay text `WE RUN TOGETHER`.
3. **Scene 3 / Manifesto Split**
   - Left: manifesto text.
   - Right: tall photography block.
4. **Scene 4 / Photo Story Strip**
   - Horizontal narrative rail (prep -> stretch -> run -> city).
5. **Scene 5 / Upcoming Runs**
   - 3-card campaign grid (image + metadata).
6. **Scene 6 / Route Map Gimmick**
   - SVG city line draws while scrolling, runner dot advances.
7. **Scene 7 / Collaborations**
   - Large campaign tiles with art direction visuals.
8. **Scene 8 / Editorial Gallery**
   - Magazine layout pattern: large + two small + large.
   - Fullscreen lightbox.
9. **Scene 9 / Join CTA**
   - Centered high-contrast conversion panel.

## Interior Pages Wireframe
- **Runs:** hero still, upcoming/past tabs, route map, recap gallery.
- **Collaborations:** hero, narrative copy, campaign gallery, video, credits.
- **Gallery:** filters (`runs`, `community`, `collabs`, `city`) + masonry/lightbox.
- **About:** manifesto timeline + mission + team portraits.
- **Join:** compact form, social proof stats, CTA.

## Tokens
- Primary: `#000000` `#0B0B0B` `#FFFFFF`
- Accent: `#E6FF00` (only interaction/highlight)
- Type: Space Grotesk, bold uppercase, wide tracking.
